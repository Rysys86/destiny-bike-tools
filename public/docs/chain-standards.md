# Chain & Speed Compatibility

## Overview

Modern chains are speed-specific. Width decreases as speed count increases. Mixing speeds causes skipping, premature wear, and shifting failure.

## Chain Width by Speed

| Speed | Outer Width | Inner Width | Brands |
|---|---|---|---|
| 5–6 speed | 7.1–7.3 mm | 3.3 mm | Universal |
| 7–8 speed | 7.1–7.3 mm | 3.3 mm | Shimano, SRAM |
| 9 speed | 6.5–6.7 mm | 3.3 mm | Shimano, SRAM, Campagnolo |
| 10 speed | 5.88–6.2 mm | 3.3 mm | Shimano, SRAM, Campagnolo |
| 11 speed | 5.5 mm | 3.1 mm | Shimano, SRAM, Campagnolo |
| 12 speed | 5.2–5.3 mm | 3.0 mm | Shimano, SRAM, Campagnolo |
| 13 speed | 5.2 mm | 3.0 mm | Campagnolo Super Record |

## Cross-Brand Compatibility

| Chain | Works With |
|---|---|
| Shimano 11s | Shimano 11s, SRAM 11s (confirmed) |
| SRAM 12s (Flat Top) | SRAM 12s only — unique tooth profile |
| Shimano 12s | Shimano 12s, some SRAM 12s (not Flat Top) |
| Campagnolo 12s | Campagnolo 12s only |

## Derailleur Capacity Formula

```
Max capacity = (large_cog − small_cog) + (large_ring − small_ring)
```

Example: 11-34t cassette + 50/34t chainrings = (34−11) + (50−34) = 23 + 16 = **39t capacity needed**

## Chain Wear Limit

- Replace at 0.5% stretch (0.75% maximum before cassette damage)
- Use a chain wear indicator tool (Park Tool CC-2, KMC checker)
