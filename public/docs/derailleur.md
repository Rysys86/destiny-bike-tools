# Derailleur Standards

## Rear Derailleur Mounting

| Standard | Mount Type | Notes |
|---|---|---|
| Traditional hanger | Replaceable derailleur hanger | Universal since 1990s |
| Direct mount (SRAM) | UDH (Universal Derailleur Hanger) | SRAM AXS 2022+ |
| Shimano Shadow+ | Traditional hanger | Friction clutch |

## Derailleur Cage Length vs Cassette

| Cage | Max Cog (Shimano) | Max Cog (SRAM) | Use |
|---|---|---|---|
| Short (SS) | 28t | 28t | Road compact, tight range |
| Medium (GS) | 34t | 36t | Road, light gravel |
| Long (GS/SGS) | 42t | 46t | MTB, wide-range gravel |
| Extra-long | 46–51t | 52t | 1× MTB, massive range |

## Cable Pull Ratios

| Standard | Pull per shift | Compatible levers |
|---|---|---|
| Shimano road 11s | 3.1 mm | Shimano STI 11s |
| Shimano MTB 11s | 3.1 mm | Shimano MTB 11s triggers |
| SRAM road | 3.1 mm | SRAM DoubleTap |
| Shimano 12s MTB | 3.1 mm | Shimano 12s only |
| SRAM AXS | Electronic (wireless) | SRAM AXS pods |

> **Rule:** Never mix cable pull ratios across brands without a Jockey Box or pull converter.
